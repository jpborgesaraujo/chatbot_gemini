# IA_python
O projeto é um chatbot Flask para a MusiMart: a interface em `index.html` envia mensagens ao backend em `app.py`, que classifica o sentimento para escolher uma persona em `selecionar_persona.py` e usa os dados de `MusiMart` para gerar respostas com o Gemini. Para executá-lo, abra o PowerShell na pasta do projeto e crie ou edite o arquivo `.env` — é um **arquivo**, não uma pasta — colocando `GEMINI_API_KEY=sua_chave_real` nele; mantenha a chave privada. Depois instale as dependências com `& "C:\Users\joão pedro\AppData\Local\Programs\Python\Python312\python.exe" -m pip install -r requirements.txt` e inicie com `& "C:\Users\joão pedro\AppData\Local\Programs\Python\Python312\python.exe" app.py`. Acesse **http://127.0.0.1:5000/** no navegador. Se o Gemini retornar 503, pode ser necessário aguardar e tentar novamente; além disso, a interface ainda diz EcoMart, enquanto os dados e as personas são da MusiMart.
